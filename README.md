# 🏎️ Legends of Speed - Ultimate Script v6.0.0

## 📖 Perkenalan Script

**Legends of Speed Ultimate Edition** adalah script Luau premium yang dirancang khusus untuk game *Legends of Speed* di Roblox. Dikembangkan oleh **Delta**, script ini menawarkan pengalaman bermain otomatis dengan fitur-fitur canggih menggunakan framework WindUI yang modern.

### ✨ Fitur Unggulan

- **🐾 Complete Pet System**: 42 pets lengkap dengan organisasi berdasarkan rarity dan crystal category
- **🌈 Trail Collection**: 75 trails valid dengan sistem auto-equip cerdas
- **⚡ Auto Farm & Collect**: Sistem antrian shop yang mencegah rate limiting
- **📊 Advanced Statistics**: Fitur export/import data dan monitoring performa (FPS, Memory, Ping)
- **🎯 Player ESP**: Daftar pemain dengan toggle ESP per individu
- **⌨️ Quick Controls**: 
  - `RightShift`: Toggle UI
  - `E`: Quick Collect Orb
  - `R`: Quick Rebirth
  - `T`: Teleport to Nearest Orb

### 🛠️ Spesifikasi Teknis

- **Versi**: 6.0.0
- **Lines of Code**: 3400+
- **Framework**: WindUI Enhanced
- **Tabs**: 12 kategori terorganisir
- **Config System**: Support profiles export/import
